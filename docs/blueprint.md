# **App Name**: funder mustghanem

## Core Features:

- Home Feed: Display events in a feed with filtering options.
- Calendar View: Calendar view for browsing events by day, week, or month.
- Interactive Map: Interactive map showing venues and event locations with filtering.
- Tourist Guide: Basic tourist guide with suggested routes and points of interest based on user interests. The AI will be used as a tool.
- Add to Calendar: Allow users to add events to their personal calendar.
- Push Notifications: Send push notifications for new events or schedule changes.
- Personalized suggestions: AI-driven suggestion of points of interests, personalized routes.

## Style Guidelines:

- Primary color: Vibrant orange (#FF9500) to reflect the energy and culture of Mostaganem.
- Background color: Light gray (#F2F2F2), almost white, to provide a clean and modern feel.
- Accent color: Teal (#008080) for interactive elements and highlights, contrasting with the orange.
- Body and headline font: 'PT Sans', a versatile sans-serif suitable for both Arabic and French text.
- Intuitive icons that are easy to understand in both RTL and LTR layouts.
- RTL-first design with clear, spacious layouts.
- Subtle animations to enhance user experience and provide feedback.
