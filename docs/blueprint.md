# **App Name**: LexConnect

## Core Features:

- Multilingual Support: Display the website in Arabic (RTL), French, and English with i18n support for adapting text, UI, buttons, and notifications based on the selected language.
- User Role Management: Enable guest, user, professional, and admin roles, each with specific permissions and access levels.
- Admin Dashboard: Provide a secure login for admins to approve/reject professional accounts, edit subscriptions, view user activity, send notifications, and export data.
- Account Validation: Implement a professional account validation workflow where professionals register, upload documents, and await admin approval to activate their accounts.
- Service Display: Showcase main services offered (Legal Consultations, Semi-digital Notarization, Commercial Transaction Management) on the home page in all supported languages.

## Style Guidelines:

- Primary color: Bronze (#CD7F32) to evoke sophistication and tradition in legal services.
- Background color: White (#FFFFFF) to ensure readability and a clean, modern aesthetic.
- Accent color: Black (#000000) to provide contrast and highlight important calls to action.
- Use a clean and professional font to convey credibility.
- Employ clear and recognizable icons to represent services and actions.
- Design a responsive layout that adapts to different screen sizes and RTL/LTR languages.
